## Context

This report covers APIVR-Δ's execution of plan step S0 from `v0-1-fs-scope.json`: applying the previously-deferred **P1-B** item from VIGIL's blank-pane root-cause-report (thread `05a53a35-a9e5-46f7-9ee2-7931ac52c700`, file `.junction/threads/05a53a35-a9e5-46f7-9ee2-7931ac52c700/root-cause-report.md`).

VIGIL had diagnosed the blank-pane as a multi-cause failure. P0 fixes (state wiring, type mismatch, localStorage reads) were applied in a prior session. P1-B — extending the Tauri 2 fs capability scope so that route components' `readTextFile` and `readDir` calls reach user-picked project paths and the nexus `$HOME/.eidolons` subtree — was explicitly deferred with severity P1.

Three live runtime errors confirmed the deferral was blocking real use: `forbidden path: /Users/henrique/.eidolons/nexus/roster/index.yaml`, the Project route's friendly catch (`No eidolons.yaml found`) masking the same denial, and `forbidden path: /Users/henrique/workspace/oss/agents/eidolons/.eidolons`.

## Changes applied

**`src-tauri/capabilities/default.json`** — replaced the bare `"fs:default"` string with `"fs:default"` retained plus three scoped permission objects:

- `fs:allow-read-text-file` with five `allow` entries covering `$HOME/.eidolons/**`, `$HOME/**/eidolons.yaml`, `$HOME/**/eidolons.lock`, `$HOME/**/eidolons.mcp.lock`, and `$HOME/**/.eidolons/**`.
- `fs:allow-read-dir` with three `allow` entries covering `$HOME/.eidolons/**`, `$HOME/**/.eidolons`, and `$HOME/**/.eidolons/**`.
- `fs:allow-exists` with the same five entries as `allow-read-text-file`.

Permission identifier strings were verified against the installed `tauri-plugin-fs 2.5.1` autogenerated permission TOML files in the local Cargo registry (`~/.cargo/registry/src/.../tauri-plugin-fs-2.5.1/permissions/autogenerated/commands/`). The identifiers `allow-read-text-file`, `allow-read-dir`, and `allow-exists` are confirmed exact matches.

**`CHANGELOG.md`** — prepended a Fixed entry under `[Unreleased]` documenting the P1-B resolution and listing all five affected routes.

**`README.md`** — added one sentence under "What GAMBIT does" noting the intentional scope bound (`$HOME` + Eidolons-shaped paths only, no arbitrary disk access).
